# 手動テストチェックリスト

運用前レビューでは、`index.html` をブラウザで開き、以下を確認します。Stock API連携、自動ログイン、画面スクレイピングは行いません。

## 事前確認

1. `index.html` をブラウザで開く。
2. 画面タイトルが「Stock正本 月次面談アジェンダ管理ツール」であることを確認する。
3. 基本情報タブ以外へ進もうとしても、開始前は進めないことを確認する。

## JSON読込と開始ゲート

1. 顧客コードに `TEST001`、対象月に `2026-06` を入力する。
2. `sample-data/sample_previous.json` を前回JSONとして読み込む。
3. 前回JSONの検証結果が成功表示になることを確認する。
4. 「前回JSONで開始」を押し、アジェンダ画面へ進めることを確認する。
5. アジェンダ画面の「過去について」に未完了事項が表示されることを確認する。
6. 初期化し、顧客コードに `OTHER001`、対象月に `2026-06` を入力する。
7. `sample-data/sample_previous.json` を読み込み、顧客コード不一致で開始できないことを確認する。
8. 初期化し、顧客コードに `TEST001`、対象月に `2026-06` を入力する。
9. `sample-data/sample_old_month.json` を読み込み、前月以外の警告が出ることを確認する。
10. 理由未入力では開始できないことを確認する。
11. 理由を入力すると開始できることを確認する。

## 例外開始

1. 初期化し、顧客コードと対象月を入力する。
2. 例外理由を空欄のまま「前回JSONなしで開始」を押し、開始できないことを確認する。
3. 例外理由に「その他」を選び、理由詳細を空欄のまま開始できないことを確認する。
4. 例外理由と理由詳細を入力すると、アジェンダ画面へ進めることを確認する。

## 繰越と状態管理

1. `sample-data/sample_previous.json` で通常開始する。
2. `status=open`、`status=in_progress`、`status=on_hold` かつ `carryForward=true` の項目が繰り越されることを確認する。
3. `done`、`withdrawn`、`carryForward=false` の項目が自動表示されないことを確認する。
4. 繰越された項目の状態を「完了」に変更し、次月以降へ繰り越すチェックが外れることを確認する。
5. 別の項目の状態を「取り下げ」に変更し、次月以降へ繰り越すチェックが外れることを確認する。
6. 新規事項を追加し、タイトル、詳細、担当、期限、状態、次月以降繰越、公開範囲を入力できることを確認する。
7. アジェンダのカテゴリが「過去について・現在について・未来について」になっていることを確認する。
8. 現在についてに中間納税の納付額・納付時期、未来についてに業績着地予測や短期経営計画を入れやすい文言になっていることを確認する。

## visibility分離

1. `sample-data/sample_internal_visibility.json` を使って通常開始する。
2. `visibility=client` の項目が顧客共有用アジェンダに表示されることを確認する。
3. `visibility=internal` の項目が顧客共有用アジェンダに表示されないことを確認する。
4. `visibility=internal` の項目が内部用メモに表示されることを確認する。
5. 共有用コピーまたは共有用印刷に、内部だけの確認事項が混入しないことを確認する。

## Stock貼付用要約

1. 面談結果タブで、決定事項、顧客側の宿題、事務所側の宿題、内部メモを入力する。
2. 出力タブで「Stock貼付用要約を生成」を押す。
3. 対象月、面談日、担当者、対象顧客コードが表示されることを確認する。
4. 今回確認事項（過去・現在・未来）、決定事項、次回繰越事項、顧客側の宿題、事務所側の宿題が表示されることを確認する。
5. 内部メモと internal 項目が「内部メモ」セクションに区分されることを確認する。
6. 添付JSONファイル名が `junkai_{clientCode}_{targetMonth}_v001.json` 形式で表示されることを確認する。
7. 「要約をコピー」を押してコピーできることを確認する。
8. コピーに失敗する環境でも、テキストエリアから手動コピーできることを確認する。

## JSON出力と翌月再読込

1. 今回JSONを出力する。
2. 出力ファイル名が `junkai_{clientCode}_{targetMonth}_v001.json` 形式であることを確認する。
3. 出力したJSONを保存し、翌月の前回JSONとして再読込する。
4. 顧客コードが一致すれば読み込めることを確認する。
5. 今回 `done` または `withdrawn` にした項目が、翌月の自動繰越に出ないことを確認する。

## 面談後チェックリスト

1. 面談結果タブの面談後チェックリストを確認する。
2. 未チェック項目がある場合、「未完了の手順があります」と表示されることを確認する。
3. 期限付き未完了項目がある場合、「期限付き宿題をStockタスクに登録した」が強調されることを確認する。
4. 「Stock貼付用要約をStockノート本文へ貼り付けた」があることを確認する。
5. 「今回JSONをStockノートへ添付した」があることを確認する。
6. すべてチェックすると「Stock保存フロー完了」と表示されることを確認する。

## 守秘・運用確認

1. Stockノート本文へ要約を貼り付ける。
2. Stockノートへ今回JSONを添付する。
3. JSONを職員PCだけに保存したままにしない。
4. 顧客データをGitHubリポジトリへ置かない。
5. internal項目や内部メモを顧客共有用として渡さない。
6. Stock API連携、自動ログイン、Stock画面スクレイピングを使っていないことを確認する。
